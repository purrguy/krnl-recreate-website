What it does

  • Attaches to the Roblox client on Windows.
  • Runs Luau on the game's own VM, not an emulator.
  • Keeps one script window open, with tabs and saved scripts.

FAQ

Is it free?

Yes. No key system.

Does it work on the live client?

Not yet. The current build is validated against Studio while client support is finished. The download page always shows the current stage.

Antivirus flags it

Anything that attaches to another process looks like an injector. Check the SHA-256 above against the file you downloaded.

Something breaks

Post the script and the console output in Discord.

Download

Windows 10 or 11, x64. Extract the zip and run krnl.exe.
