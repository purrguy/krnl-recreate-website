Obfuscate

Encrypts a script for krnl.SECURE_RUN. The output runs only with the same password.

Format

  • PBKDF2-HMAC-SHA256, 512 rounds, 64-byte key
  • HMAC-SHA256 counter keystream, 16-byte nonce
  • HMAC-SHA256 tag over nonce + ciphertext
  • base85 container, version byte, length-prefixed
